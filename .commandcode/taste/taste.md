# Taste

## Workflow & tooling

- Wants project startup collapsed into a single streamlined command that handles prerequisites (env file generation, database up, seeding) rather than a multi-step manual setup. Confidence: 0.6

## Communication

- Prefers beginner-friendly, step-by-step instructions that assume no prior technical knowledge (exact commands to type, expected output, how to stop, common errors with fixes) over terse or expert-level instructions. Confidence: 0.6
